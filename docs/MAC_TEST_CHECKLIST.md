# GSN Paints macOS test checklist

These steps are required on a real Mac. This Windows machine can only prepare the workflow and scripts.

## Installation

- [ ] Launch the DMG and install the app.
- [ ] Confirm the app opens with the correct GSN Paints name.
- [ ] Check Apple Silicon vs Intel build correctness.
- [ ] Confirm Gatekeeper steps are documented and work.

## First-run and restore

- [ ] Create the first administrator user.
- [ ] Log in and confirm data loads.
- [ ] Make a purchase, production, sale, and payment.
- [ ] Create a backup as a new file.
- [ ] Replace an existing backup file.
- [ ] Restore the backup and confirm the app restarts.
- [ ] Confirm data persists after quit and relaunch.

## Cross-platform validation

- [ ] Restore a Windows-made backup on macOS.
- [ ] Restore a macOS-made backup on Windows.
- [ ] Confirm `Cmd+C`, `Cmd+V`, and other standard keyboard shortcuts work in text inputs.
- [ ] Confirm the app fits a 13-inch MacBook screen.
- [ ] Confirm the app works without internet access.

## Uninstall and upgrade

- [ ] Upgrade over the old app version and preserve data.
- [ ] Uninstall by moving to Trash and confirm data remains unless intentionally deleted.
